---
description: Markdown style for harim-base user. Path-scoped to *.md files.
paths: ["**/*.md"]
---

- ATX headings (`# H1`, `## H2`); never setext (`=====`).
- Backtick-fenced code blocks with language identifier.
- Reference-style links for repeated URLs; inline for single use.
- Tables: pipe + header separator. No HTML tables.
- Korean: NBSP between number and unit (`5 kg`, `100 m`).
- One trailing newline at EOF.
- No trailing whitespace.
